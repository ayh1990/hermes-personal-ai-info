Data handling

Privacy policy

This policy describes the private Google Workspace integration operated by the owner of this personal assistant.

Information accessed

The integration can access the Gmail messages and metadata, calendar entries, Drive files and Sheets content permitted by the owner's Google consent. It uses information relevant to the owner's assigned task.

Purpose and local storage

Google information is used for the personal functions described on the homepage. OAuth credentials are saved locally with restricted file permissions. Task conversations, downloaded files and generated results may remain on the owner's device or in the owner's chosen storage until the owner removes them.

Optional cloud processing

Local AI is the default. When cloud review is selected or needed, relevant task content may be sent to the configured OpenAI or OpenRouter service. Those providers process requests under the owner's account settings and their service policies. Cloud processing of Google-derived content must use data controls consistent with Google's Limited Use requirements.

This installation does not train or fine-tune models on Google user data. Google data is not sold or used by this installation for advertising. Access and transfers are limited to the requested functionality, subject to the Google API Services User Data Policy.

Revocation and deletion

The owner can revoke this app in Google Account connections. Revocation stops future authorized API access; previously stored copies remain until deleted from the owner's device and chosen storage. The owner can remove local authorization files and task records, and manage data already submitted to cloud services using those services' controls.

This information site

These static pages contain no assistant login, Google authorization form or analytics scripts. If hosted on GitHub Pages, ordinary hosting records are handled under the GitHub Privacy Statement. Google credentials and account contents are not part of the website source.

Contact and updates

The operator is the ayh1990 GitHub account owner. Contact information for the OAuth app is available on its Google consent screen. This policy will be updated when the integration's data practices change.
